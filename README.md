### Project Description
This project consists of three exercises that demonstrate the use of JSON data structures, JavaScript fetch API, and jQuery for DOM manipulation and event handling.

### Question 1 – Create and Structure JSON Data
This question involves creating a valid JSON file named `books.json` containing information about two books, including their titles, authors, publication years, and genres.

**How to run:**
1. Open the project folder.
2. Open `books.json` using Visual Studio Code.
3. View the JSON structure and verify that the data is valid.

### Question 2 – Retrieve and Display JSON Data
This webpage uses the JavaScript `fetch()` API to retrieve data from `books.json` and display the selected book information, including the first book's title, the second book's author, and the genres of both books.

**How to run:**
1. Open the project folder in Visual Studio Code.
2. Open `books.html`.
3. Right-click and select Open with Live Server.
4. View the retrieved book information in a web browser.

### Question 3 – Compare Native JavaScript and jQuery
This webpage demonstrates three jQuery operations: modifying text using `.text()`, adding a CSS class using `.addClass()`, and handling button clicks using `.on()`.

**How to run:**
1. Open the project folder in Visual Studio Code.
2. Open `jquery-dom.html`.
3. Right-click and select Open with Live Server.
4. Check the modified text and CSS styling.
5. Click the button to display the alert message "Button clicked!".
